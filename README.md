
# Funnel Drop-off Analysis

## Project Overview

This project analyzes user behavior through a conversion funnel to identify where users drop off.

## Dataset

The dataset contains user events across different funnel stages.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Steps Performed

- Loaded the dataset
- Cleaned missing values
- Counted unique users at each funnel stage
- Calculated conversion percentages
- Identified the stage with the highest drop-off
- Visualized the funnel using charts

## Result

The highest user drop-off occurs between **Details Filled** and **Email Verified**, indicating that the email verification process is the main bottleneck.
